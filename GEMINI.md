# Workspace Rules & Guidelines

## File & Folder Storage Rule
- **Explicit Location Specified**: When generating files or folders and the user specifies where to save or store them, always save them in the user's requested location.
- **Unspecified Location (Default)**: When generating files or folders and the user does **not** specify or explain where to store or save them, always store and save them in the `storeroom/` folder (`d:\Jarvis\storeroom`).
